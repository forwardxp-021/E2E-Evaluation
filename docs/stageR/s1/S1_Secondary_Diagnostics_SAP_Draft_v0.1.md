# Secondary Diagnostics SAP — Draft v0.1

**DRAFT_FOR_SCIENTIFIC_OWNER_REVIEW.** No diagnostic has veto power over a valid Primary BDD result. These analyses neither replace Primary nor authorize encoder selection from Q/D.

1. **H vs H+RBR prediction:** target is assigned baseline/treatment arm, not mechanism success. Fit logistic ridge readouts with intercept, equal arm weights, identical grouped D folds and C∈{.01,.1,1,10}; select by mean validation log-loss, ties within 1e−12 choose smaller C. Five log-group folds if ≥20 logs, otherwise three if ≥12; less is NOT_EVALUABLE. Scalers fitted inside folds; concatenation adds no hidden nonlinear layers. Refit once on D, freeze before E. Primary diagnostic risk is log-loss(H)−log-loss(H+RBR), averaged within log then over E_AB logs; 95% log-bootstrap interval, one-sided improvement hypothesis. Treatment arm prediction is readout-specific information, not proof of causal unknown-behavior discovery. No perfect-H exclusion rule.
2. **Semantic retention:** nine existing CORE targets from `../r0/manifests/r0_d1_core_semantic_targets_v0.1.json` (verify actual source binding in manifest before use). Use their existing units/validity; no new semantic targets chosen on E. Fit ridge for continuous targets (λ∈{.01,.1,1,10}) and the same logistic grid for categorical targets; grouped D selection, U remains encoder-selection-only. Continuous report R² and MAE, categorical balanced accuracy and log-loss; log-bootstrap intervals. Preserve R0's original results. These future probes are diagnostics, not new universal semantic-retention gates.
3. **Geometry:** fixed covariance spectrum, effective rank exp(entropy of normalized eigenvalues), participation ratio, column variance, norm and within/between-arm distance distributions. D baselines define reference. Report E descriptively with log-bootstrap intervals; do not infer geometry causation from higher rank or BDD gain.
4. **Shortcut/source audit:** inspect source/log overlap, map/source availability, initial speed and missingness associations, and nearest D neighbor distribution. A source/map classifier uses same grouped split/readout budget as above only if multiple sources/maps exist with independent groups per split; otherwise NOT_EVALUABLE. Log-ID classification with one row/pair per log and unseen IDs is not meaningful; do not manufacture train/test windows from a log. No claim that chance source prediction proves absence of leakage. If an actual firewall breach is found, report protocol validity breach independent of whether BDD is positive; it is not a discretionary predictive-risk veto.
5. **Paired controlled BDD:** when unpaired is Primary, use the frozen complete E_AB pairs as supporting data, α=.05, m=20 pairs, π=.50, shared H/RBR draws and log-level swap null. Report detection differences and paired mechanism effects. Its matched null does not estimate unpaired release FPR. When paired fallback is Primary, do not count the same contrast again as independent secondary evidence.
6. **Attribution:** O validates the prescribed morphology; F0/H quantify known signals. Nonreactive traffic and frozen software assignment limit interpretation. Do not identify a particular latent cause, human experience or general unsafe behavior from an alarm. Temporal-order ablation is optional future work, not mandatory and not a rescue route.

Multiplicity: one fixed 11-hypothesis secondary family: one incremental-risk test, nine CORE semantic probe tests against the corresponding no-information baseline, one paired H/RBR BDD improvement test. Holm .05; unavailable hypotheses contribute p=1 rather than shrinking the family. Geometry and source audits are descriptive, not unreported extra significance searches. For continuous semantic tests, baseline is D-trained intercept-only risk; for categorical targets, baseline is D class-proportion risk; use paired E log-mean loss difference for hypothesis testing, retaining R²/balanced accuracy as descriptive scores. Sign-flip null is valid only under the stated symmetric log-difference assumption; otherwise use centered log-bootstrap tail tests and record that approximation. Exactly one readout grid per diagnostic, no feature expansion, no threshold tuning on E.

The primary H+RBR diagnostic is bounded, development-informed and explicitly Secondary. Positive BDD with null risk gain supports pipeline detection utility, not proven better geometry. Positive risk gain with null BDD does not rescue Level 2.
