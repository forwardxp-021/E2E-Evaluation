## Route B仅概念设计，不给数值、不实施

1. 先界定行为构念：两次负加速度episode，中间持续的near-zero纵向加速度/近似保持速度；注明坡度、阻力、controller和速度测量的定义。自然“松刹”不必严格a=0，仿真也不能凭踏板词语代替实际轨迹。
2. 新协议分别规定command意图与realized coast条件，例如可容忍的a带、持续时间、速度漂移与两次制动可分性；具体阈值必须有前瞻物理/测量依据，本轮不选ε、duration、release加速度或参数网格。
3. 不能沿用要求正回升的旧release_fraction gate并声称同一个construct；原TSB版本、参数、资格状态永久留存，新版本另命名并明确差别。
4. 先独立授权有限development/工程预算，再以与开发适当独立的冻结样本资格验证；任何技术/科学失败按新预注册分母和停止规则保留，不从成功者挑cohort。

## 建议及停止点

若论文当前核心是“固定误报与预算下，学习表示是否优于强H”，Route A科学上可接受；near-zero coast不是回答该有限问题的必然前置条件。建议采用A，精确命名并保留阴性结果可能性，不因担心H太强而重开无限TSB开发。

只有当Owner把自然滑行式两次制动明确认定为论文当前不可替代的问题，才值得单独审查B的必要性和预算。本轮到语义决定材料为止；不修改v2.4原件或冻结科学合同，不自动重开TSB或RBR训练。
