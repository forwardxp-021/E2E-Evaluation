# TSB-Coast C0 — Owner决策备忘录 v1

## 先用大白话回答

**当前这套nuPlan生产模型只能支持明确简化的加速度命令代理，不能证明真实“松开驱动与制动，让车自己滑行”。** 它没有分开的驱动/制动执行器和被动阻力模型。把参考加速度写成0仍可能让LQR主动控速；即便把最终加速度请求设0，模型也保留上一脚的滤波尾巴。

能力判定：**`ABSTRACT_COAST_PROXY_ONLY`**。这是当前接口可表达且可设计观测的代理能力，不是现行LQR已实施coast模式，也不是Owner已接受代理作为论文物理构念。

## 1. 实际输入与模型

已核对旧生产六份resolved config及实际源码：TwoStageController+LQRTracker+KinematicBicycleModel。纵向输入为期望加速度，另有转向率；无独立驱动/制动扭矩，无空气/滚阻/坡度/发动机/回收受力项。官方模型默认加速度低通tau=.2s；在.1s一步后，零请求仍保留2/3的旧a。这是模型数学记忆，不是真实被动阻力证据。

## 2. 中段a_ref=0与动作观测

a_ref=0只定义reference speed平台。约1s预瞄和速度误差仍可能使最终LQR请求非零。现有recorder可记录滤波前净a请求和shadow，不能看见轮端力，也不能自动看见未来gate后的命令。零命令、零实测a、零踏板、零驱动/制动扭矩不能互相推出。

## 3. C2与机制资格需要怎样修订

保留“两脚制动+公平配对”的思路；若接受代理，须新定义显式零纵向请求模式、最终接口观测及滤波一致性，不能只冻结速度平台。新的binding/observer是未来有限工程提案，本轮未实现。原近零带/持续时长、漂移和正恢复规则降为待审诊断，不再默认是物理自由滑行定义。真实被动力下减速、下坡加速均可能合格，关键先看动作和模型证据。

本轮没有新制动幅值、时长、阻力参数或容差。若必须证明真实执行器关闭，当前模型缺证，需要另行最小技术/范围决定，不能伪称已实现。

## 4. F_match与P1阻断

原±.01压力测试及raw mean_abs_accel敏感性证据原样保留，`TSB_COAST_P1_PREFLIGHT_BLOCKED`不变。人为扰动≠实际数值误差≠执行器不可观测≠真实两臂物理差异≠配对容差。原.02预算有运动学意义，但对新construct不自动获批，也不自动作废；如需完整测量学审查，单列有限M1，不能直接扩阈值、换导数或取消压力测试。

## 5. 是否可以直接继续P1

不能恢复旧授权。可避免换车辆模型的最小未来路径是“明确代理合同+小范围模式门/post-gate观测”，仍需Owner接受代理主张、测量与执行绑定和新授权。若目标必须是真实物理滑行，则小adapter不能弥补缺失的受力/执行器通道，不应无限调C2来凑PASS。
