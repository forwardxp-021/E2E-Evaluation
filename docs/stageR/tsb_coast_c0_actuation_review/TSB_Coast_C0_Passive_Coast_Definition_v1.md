# TSB-Coast C0 — 自由滑行构念与代理分层定义 v1

本轮Owner前瞻澄清：研究目标为 **`BRAKE → PASSIVE_COAST → BRAKE`**，中段解除主动纵向驱动与制动，允许真实被动力自然改变速度，而不是强制a=0。本文件是新修约提案，不追溯改写P0/P1。

## 1. 物理层目标

正式中文名称建议：**制动—解除主动纵向驱动与制动的自由滑行—再次制动**。

第一和第二阶段有真实、分离的负加速度及相应制动意图/实现证据。中间阶段没有主动驱动和主动制动请求，实际速度由声明的被动力及残余执行器响应决定。若采用真实车辆/受力模型，需要明确档位、动力总成连接、发动机拖曳、回收使能和坡度的定义；“松踏板”本身不保证没有回收/发动机制动力。

能量回收通常需要控制命令，若科学定义要求零主动制动，不能未经声明就把回收扭矩划入“被动阻力”。发动机拖曳是否属于所研究滑行模式的被动力，需要前瞻说明动力总成状态。当前生产模型两者皆未表达，本轮不引入其参数。

## 2. 不等价的四种观测

| 观测/定义 | 能支持 | 不能推出 |
|---|---|---|
| 无踏板请求 | 指定传感/控制层的踏板状态 | 无自动驱动、回收、坡度补偿或轮端扭矩 |
| 无主动驱动/制动轮端力或扭矩 | 直接执行器层的物理滑行模式，仍需确认观测完整 | 净加速度为0；路面/坡度阻力会改变速度 |
| 模型输入u_accel=0 | 当前抽象接口的零加速度请求 | 零踏板、两个力各为0、模型应用a立即为0 |
| 轨迹测得a≈0 | 某时间段运动学结果 | 无主动驱动；定速巡航补偿阻力也可a≈0 |

## 3. 当前平台可支持的代理合同（待Owner接受）

能力结论为`ABSTRACT_COAST_PROXY_ONLY`。建议短名 **ZERO_LONGITUDINAL_COMMAND_COAST_PROXY**，不是TRUE_PASSIVE_COAST。

代理假设：固定官方平面kinematic bicycle，无阻力/坡度/动力总成纵向力，保留官方加速度低通；不重置上一时刻加速度，不直接改车速，不强制实际恒速。中段在**最终送入模型的接口**将抽象纵向请求设为零，并禁止速度误差/未来第二脚在该模式内改变这个最终请求。模式结束后才恢复前瞻冻结的制动控制。

这可在不换官方车辆模型的条件下表达一种理想化惯性滑行+滤波记忆代理；但不是现行未修改LQR已经具备的功能。版本化控制门/记录绑定尚未实现，更未获本轮实施或科学执行许可。无阻力并不证明真实道路阻力可以忽略，而是必须公开的简化假设。

可核验项建议：当前时刻模式身份/边界、pre-gate LQR请求、post-gate模型输入、数据源/配置hash、状态加速度滤波一致性、真实速度和两段制动。数值零的检查精度需按接口赋值/序列化/观测误差前瞻说明；本轮不设新的epsilon、时长、阻力系数或容差。

## 4. 真实运动与原“近零”条件的地位

真实自由滑行可因阻力显著减速，也可因下坡而加速；a落在±.20不是必要条件。主动驱动补偿阻力可使a=0，所以近零也不充分。原持续正加速度排除适合禁止人为恢复的旧代理，但在有重力的物理模型中，正a必须结合执行器/力平衡解释，不能自动等同踩油门。

对于当前无坡度无阻力代理，正a或不合模型的速度恢复仍可作为控制门/符号/滤波实现异常诊断；“多大、多长判失败”须新合同经证据批准，不沿用P1数值当新构念定义。速度漂移应与声明模型的预测和不确定性比较，不要求Δv=0或Δv>0。

## 5. 科学适用边界

本代理可研究简化控制条件下两段制动与中段解除抽象请求的时序机制；不能声称自然驾驶员松踏板、真实车辆动力总成零轮端力、被动阻力真实性或一般未知行为发现。若Owner研究目标要求这些真实物理通道，现有栈不够，需另行审查受力/执行器模型或有执行器观测的数据；本轮不切换平台。
