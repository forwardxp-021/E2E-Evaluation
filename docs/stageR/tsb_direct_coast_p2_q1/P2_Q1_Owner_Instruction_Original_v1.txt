## 六、正式机制资格

对Baseline要求：

- 恰好一段合格制动；
- 实际峰值≥0.80m/s²；
- 有效支持时长≥0.40秒；
- 门槛内制动剂量≥0.35m/s。

对Treatment要求：

- 恰好两段合格制动；
- 每段峰值≥0.80m/s²；
- 每段有效支持时长≥0.40秒；
- 每段剂量≥0.35m/s；
- 两段有效分离≥0.70秒；
- 中间18个控制步最终纵向请求严格为0；
- 请求实际到达官方模型；
- 车辆状态持续推进；
- 模型加速度滤波关系符合冻结方程；
- 无未解释的主动正向恢复。

资格计算必须使用冻结的median3真实速度、physical-time gradient及有效域规则。

低速、参考速度floor及时间有效性检查不得取消。

旧近零加速度、速度漂移及正恢复数值作为已批准的诊断指标保留。

不允许根据某个SESSION实际曲线重新选择测量区间或改变机制门槛。

## 七、F_match与额外平衡

只有两arm均通过技术、机制和安全检查，才进行正式配对判断。

四项容差保持：

```text
mean_speed ≤ 0.10m/s

end_minus_start_speed ≤ 0.15m/s

path_length ≤ 0.80m

mean_abs_accel ≤ 0.02m/s²
```

全部使用冻结的raw速度、规范物理时间、导数、舍入和比较方法。

额外要求：

```text
negative_dose_delta ≤ 0.15m/s

each_Treatment_peak_vs_Baseline_peak
≤ 0.20m/s²
```

不允许用参考曲线代替实际轨迹。

如果arm级条件失败，正式F_match应标记：

`NOT_EVALUATED_ARM_GATE_FAILED`

允许保存已观察到的单臂描述符，但不得把描述性差值伪报为正式资格PASS或FAIL。

若两个arm全部完整，F_match正式FAIL即为该pair的科学FAIL，不得重新运行寻找合格结果。

## 十、执行预算及停止规则

批准：

```text
PAIRS = 20

INITIAL_ARMS_MAX = 40

GLOBAL_ATTEMPTS_CEILING = 42

TECHNICAL_RETRY_AUTHORIZED = 0

SCIENTIFIC_CPU_BUDGET = 57600 seconds

PER_ARM_WALL_LIMIT = 1200 seconds
```

42是累计预算天花板，不是当前42次均获授权。

此次正式授权仅覆盖原40个arm各一次首次执行。

科学attempt在子进程启动前持久化领取。

每个arm采用独立新进程与全新runner、planner、tracker、model和回调实例。

累计CPU必须包含实际子进程和可计量的后代进程，预算账本不可重置。

中断、异常退出、重复输出目录或无法确定已消耗预算时，fail closed。

禁止通过删除运行账本、改run ID或重新创建目录获得额外attempt。

### 首次科学失败

立即停止整个P2。

报告：

`P2_QUALIFICATION_FAILED`

记录失败pair、arm、首次失败条件及全部已完成结果。

后续原定成员保留在冻结分母中，标记NOT_RUN_AFTER_STOP。

不执行剩余名单，不替换失败SESSION。

### 首次技术失败

立即停止整个P2。

报告：

`P2_INFRASTRUCTURE_BLOCKED`

保留真实attempt、原始日志、错误位置和已暴露科学结果。

不自动retry。

只有Owner后续独立批准技术修复/重试，才能考虑恢复。
