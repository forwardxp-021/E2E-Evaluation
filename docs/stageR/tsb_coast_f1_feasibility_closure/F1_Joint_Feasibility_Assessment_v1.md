# F1 — 双合格制动、零请求滑行与整体匹配的联合可行性 v1

| 层次 | 结论 | 证据范围 |

| 理想运动学 | 存在不矛盾的兼容空间 | 既有C2参考等冲量/等时间重心；不是LQR/model实现证明 |

## 1. 【数学推导】运动学不存在逻辑矛盾

在共同初速与时域下，令b(t)为减速度，J=∫b(t)dt，M=∫t b(t)dt，则末速度v(T)=v0−J，连续理想位移=v0T−TJ+M。两段制动置于共同重心两侧，等J/等M可以保持净降速和路径；非正加速度下绝对加速度积分也等J。零请求中a=0是该无滞后理想化模型的简化，不是当前官方model的物理声明。

此前冻结C2参考本来就具有共同J=2.61 m/s、M=7.83 m、时间重心3秒；两脚参考峰与Baseline参考峰差0.145 m/s²。因此失败不能证明“双脚+中间零请求+整体匹配”在纯运动学上互斥。该例仅复述既有参考设计，不是新参数、仿真或有效机制证据。

连续解析平均速度、80帧算术均值、raw gradient mean_abs_accel、离散XY路径不是可任意互换的量。即使J/M理想相等，也须按未来冻结算子逐项验证实际离散匹配，不能由两个连续矩条件宣布全部F PASS。

## 2. 【实测+源码】当前约束的组合

短参考、逐步current-speed重锚、1秒预瞄、第一脚前common-future与第二脚前COAST门控导致请求面积变成两个短衰减脉冲。官方滞后再压低峰值、增加尾部。Baseline提前请求和长脉冲响应的综合面积更大。因此等参考J/M没有被当前复合、时变闭环映射保持。

已公布的净速度变化差约1.18552 m/s，路径差约6.50497米；不能只把问题当作峰值0.757略低于0.80的小缺口。仅让两脚刚越过0.80/0.35并不保证全窗剂量、时间重心和四F同时匹配。

## 3. 补足净降速与峰值平衡是否冲突？

目前Treatment冻结代理峰比Baseline低约0.609 m/s²，远大于原逐峰0.20预算；这是事后幅值描述，不补做联合资格。若将来仍保留这份Baseline，原峰值平衡在数学上还要求每脚处于Baseline峰±0.20范围；所以“达到最低0.80”并不足够。

总面积由峰高、有效持续时间、肩部和尾部共同决定，不由峰高单独决定。两次制动有可能通过不同持续形态达到同总面积而不超过峰值范围，故不存在仅由当前数字推出的必然矛盾；但固定短窗+当前LQR下降请求能否做到，没有证据。不能将现在的整条波形统一放大、按一个增益反推新幅值，忽略重锚/门控/滤波后保证通过。也不能只算0.4秒支持内面积上界就忘掉门槛外真实剂量，从而伪证不可行。

## 4. 是否必须改controller或model？

零请求的表达与核验已经成立，没有证据表明必须改官方model。模型滞后也不是异常，不能为拿到PASS把它取消。未来前瞻性机制的时间结构/共同绝对参考等概念可能改变请求分配，但其是否足够尚未证明，本轮不定义新版本、不选参数、不建议实施某个控制器修改。

若另行改变planner参考锚定、LQR或model，将改变干预实现和可比性，须独立版本、同臂公平绑定、重新资格/容量/暴露审查；不是旧C2技术修补后恢复授权。不能把修改model当作最小成本默认路线。

## 5. 论文科学问题与单SESSION边界

研究目标是受控、可解释行为变化下固定误报和样本预算的RBR-vs-强H效用比较。基准机制的改变会改变适用域，未必改变这一总体问题，但也不自动有Primary适用资格。不能为了让H难检而选择新机制。

该SESSION支持“当前C2实现失败，零请求接口有效，请求层剂量不足是主要原因”的具体结论。它不支持所有nuPlan场景可行率、所有Coast机制不可能性、新参数必然成功或未来RBR/H输赢。仅凭理论兼容空间，不足以建立值得重开开发的可信联合匹配依据。

## 路线判断

**推荐路线一：关闭当前Coast基准开发。** 这是资源与研究范围建议，不是普遍不可行性定理。当前缺少新的联合匹配可行性证据，也没有理由把自然滑行双制动设为RBR研究的唯一入口；不推荐用剩余账面预算开始新参数迭代。
