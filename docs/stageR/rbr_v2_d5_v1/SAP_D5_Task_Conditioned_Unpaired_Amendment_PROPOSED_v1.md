# SAP-D5-TCU v1：任务标准化不配对BDD修约草案

**STATUS=PROPOSED_ONLY；OWNER_APPROVAL=NOT_GRANTED；EXECUTION_AUTHORIZED=false。**

本草案是D5唯一优先推荐修约版本。它不修改或激活S1/S1R，不将D3/D4重判PASS，也不接续任何停止的科学账本。D4配对条件随机化仍为辅助候选，不是本草案Primary方法。

## 1. 研究目标与适用范围

在一个事前声明的任务总体q*上，判断固定版本管线的行为表示分布是否变化，并比较固定RBR64与完整H30的校准和检测效用。首次研究仅在一个冻结任务/来源框内；不作任意城市、道路、场景混合或在线部署保证。

保留RBR-vs-H30为允许失败的比较；不把正增量预设为必须成立。论文的主科学问题是可校准、可解释、可复现的版本行为分布评价，当前双制动是机制/敏感性正控制，不是一般行为发现的充分模型。

## 2. 形式定义

v为行为版本，C为版本作用前或外生固定的任务信息，Z_r为表示。C可包含地图/道路任务、初始状态、干预前交通和采集来源，具体字段、边界、q*与共同支持规则必须在新结果访问前冻结。**禁止用制动后速度、成功、安全、mask结果、表示或报警选择C、q*或名单。**

C不包含唯一SESSION/LOG ID；来源指共同支持的采集框或环境类别。仿真重置的初速度可以是外生条件，但真实部署中初速度可能已受版本此前行为影响，不能未经论证当作外生混杂变量。干预后mask不作为事后匹配条件；同条件A/A中的测量协议/缺失机制不一致应报告测量迁移，不能假定全是驾驶行为变化。

`P_v^{q*}(Z_r)=∫P_v(Z_r|C=c)q*(dc)`。

零假设`H0_r^{q*}:P_0^{q*}(Z_r)=P_1^{q*}(Z_r)`；它是任务标准化后的观测分布零假设，不是所有c上的完整条件分布相等、因果安全等价或无任何未知行为。C不足以解释潜在场景因素时，不得宣称完全消除混杂。

`BDD_r(q*)=P_{release~q*,π=.5}(alarm_r)`，`ΔBDD(q*)=BDD_RBR−BDD_H30`。α=.05、m=20独立SESSION每侧、π=.50、δ*=.10不变。诊断同时报告FPR_r(q*)；若改变q*，就是新的目标总体，不能沿用旧阈值/结果冒充同一参数。

## 3. 数据设计及可观测性

不同SESSION分配给reference和target，不允许一源上两侧；不要求同SESSION的反事实双臂供检测器输入。目标的20源中事前随机指定10源为Treatment，另外10源Baseline；reference20源Baseline。两表示共用抽样、权重、目标处理mask及预算；同一数据的两表示报警仍配对比较。

q*通过事前来源框及可实现的采样设计定义。优先同一共同任务来源框的随机分配/分割；若使用有限分层/配额近似共同C分布，须披露近似及残余混杂，不得称精确条件检验。固定配额下样本不必iid，原公式只称“无偏两样本形式”，实际校准和区间必须复制该采样设计。未定义可执行q*和来源身份之前不得领取run。

共同支持不足、未知来源或测量协议不可比时返回NOT_ASSESSABLE/INCONCLUSIVE，报告覆盖率与完整排除原因；不能当作无漂移、静默删样或在结果后寻找替补。U/旧D/最终cal/V/C角色互斥及S1R污染政策保持；现有63个相关D来源已暴露，不进入本方法独立确认。

## 4. 检测器与数值管线

固定epoch30及normalizer、Canonical83合同、H30原始30列不变。保留原RBF与二次MMD²公式，负值不截断；每表示一个外部D_fit scaler及同一数学median-positive-distance带宽规则，零监督投影/核/seed搜索。

**H30原冻结尺度管线当前未通过数值可解释性审查；不能直接激活。** 新管线建议采用有单位的测量分辨/误差界u_j支持的尺度下界，例如`scale_j=max(SD_j,u_j)`，但u_j必须由独立物理/数值oracle、采样和误差传播证书给出，按单位转换同步变化；不得取“使RBR领先”的值。该公式是待审的预处理修约方向，**不是已经定值、可执行的scaler**。RBR的尺度稳定性也需同原则审查，不能给学习表示额外调优预算。无法认证u_j时保留阻断，不临时设epsilon或删H列。常量/退化核处理须在执行合同中明确，不能把不报警退化器当有效检测成功。

此项改变原近零SD≤1e−12→scale1规则，须新pipeline身份和独立D；保留原尺度/带宽及全部D3/D4结果。新D_fit来源数只可按稳定性证据决定，D5没有授权重拟合正式管线。

## 5. A/A、校准与A/B

* 真A/A：相同版本和测量流程，从同一事前任务总体随机分割的不同SESSION。不得用已知干预pair随机翻转伪装A/A；同一Baseline复制两侧也不是独立A/A。
* 跨来源同版本：若存在未控制任务变化，观测分布可以真实改变。只有null可辩护的子设计才计入FPR；其余单列transport stress，不把报警自动判错。
* 外部D_AA_final_cal、独立AA评价和AB评价互斥，且与D_fit及已暴露方法开发来源互斥。C保持保护。
* 校准固定1999个AA release，原seed2026091101及1900阶统计量；alarm iff T>threshold。按每个已冻结表示管线各一个阈值，本草案不采用D4每release反事实交换阈值。
* A/B保持原固定SDC科学版本、同q*、m20/π=.5、真实轨迹及机制/匹配/安全与完整失败分母，不以报警选样。不改SDC来人为制造RBR优势。
* 独立AA/AB各10000共享draw，原数值精度规则和上限不变；draw不是独立来源。不得在评价池上重新校准或更换scaler。

## 6. 推断、成功与停止

保留来源cluster-aware推断：角色分别重采来源权重，所有同源臂/表示/失败同行；每draw两侧分配不同原始ID，不能用bootstrap副本冒充新来源。外部cal重采只传播阈值不确定性，不能改原点估计。原2000外层/2000内层作为待验证数值预算；按真实q*/分层设计重采，检验源域coverage和有效唯一来源支持，不能因失败replicate删样。

保留原两表示同时95%FPR上界≤.075门及原Δ成功/失败/不确定规则：校准和完整科学资格有效，源级CI下界>0且点Δ≥.10才支持优势；有效CI上界<.10不支持实用增量；否则INCONCLUSIVE。校准失败或覆盖未建立时不得声明优势或正式效用失败。若扩展多个任务为正式主张，须另冻结多重性及N，不能重复使用只有两表示的尾概率预算。

开发阶段要检验已知零效应及Δ为0/.10/.20假设下的完整源级区间与power，构造假设公开；不把合成oracle当真实认证。按原SAP要求选择满足coverage/power的最低成本包络。若公平、有效校准后H的保守检测率下界已使`1−P(H报警)`小于.10，则原优势目标缺少可达空间，建议停止该任务Level-2确认；不得调难任务、削弱H或换encoder。没有这种总体界时，当前有限池饱和只作开发性停止投入理由，不能宣称总体已被证明相等。

## 8. 执行与预算状态

本轮新增来源/arm/下载/训练/Primary/V/C全部0；不批准240源。

120新源(40cal/40AA/40AB)只是m20不配对裸计算pilot下限，不含D_fit且不支持源bootstrap认证。原小型正式规划320=80cal＋80AA＋160AB仅在一个可辩护任务总体中仍需D验证；V本身240源，cal另列，C未定且保护不动。若任务/来源可用量不足，关闭当前Level-2投入、保留Level 1，不缩m、改π或自动借D4paired。

阻止执行的必要未定项：C/q*及来源框身份、u_j误差证书/唯一scaler版本、真AA协议、独立来源容量、完整区间覆盖与功效、最终V/C N及资源授权。它们不是被本草案暗中批准的默认值。下一步优先完成零执行的测量与任务总体设计证书，再决定是否值得付出新的D预算；本草案不能直接交runner执行。
