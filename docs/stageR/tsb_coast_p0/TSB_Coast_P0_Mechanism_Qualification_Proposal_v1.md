# TSB-Coast P0 — 全新机制资格合同提案 v1

状态：`PROPOSED_NOT_OWNER_FROZEN_NOT_EXECUTABLE`。拟命名 `TSB_COAST_MECHANISM_v1`；绝不调用或改写旧Option-A资格函数。数值是物理与采样尺度的初始规格，尚无新数据支持，若P1显示不满足不能事后放宽换PASS。

## 输入与测量有效性

只用官方runner真实current-ego记录，80个有限、严格递增的时间戳。先以整数微秒相对首帧计算秒，标准步长.1s，建议允许偏差≤1e−6s以覆盖微秒量化；缺帧、重复/乱序、任一非有限值均MEASUREMENT_INVALID，不跨洞压缩，不补帧或用planned替代。首尾应为0和7.9s。未授权实际测量，本轮没有生成80帧新闭环数据。

主测量沿路径切向加速度代理 `a=d(median3(speed_magnitude))/dt`，median3边界复制、physical-time gradient edge_order=2，沿用可审计公式但新建analyzer版本。它是速度模的切向变化，不能在侧滑时冒充body-x加速度；要求前向、路线跟随域，不对自然踏板作主张。raw speed、raw derivative、passive actual-LQR加速度并列，三者不混成一个量。

候选分析域固定episode[1.1,5.5]s；precontext和posttail全窗另报，不能择优裁剪。算法先在该域识别制动支持和间隔，不按名义峰位挑一段“最好看的”滑行。共同预瞄引发的早期减速单列；若侵入分析域成为额外合格制动段，不能删去。所有阶段边界统一用时间支持；采样支持时长t_last−t_first，不用N×dt冒充已观测持续时间。可插值边界仅作描述，不用于增加合格时长。

## 待审数值及理由

| 项 | 建议规则 | 理由及限制 |
|---|---|---|
| 每次制动 | 连续a≤−.6m/s²支持≥.4s；峰值幅值≥.8m/s²；段内负加速度时间积分≥.35m/s | 至少5个10Hz点跨.4s，区别单点噪声；.6是近零带.2的3倍；峰.8和降速剂量防止浅波纹冒充一脚。非自然驾驶人口阈值 |
| 段数 | Treatment恰好2段，Baseline恰好1段；两臂都需剂量有效 | 同一算法，不用旧release fraction，也不按预期段数合并失败 |
| 有效间隔 | 第一制动支持末至第二支持首≥.7s | 为.5s near-zero core及至少两侧各.1s过渡留最小余量；不是控制器一定能实现的承诺 |
| near-zero core | 间隔内至少一个连续区间，|a|≤.20m/s²且支持≥.50s | ≥6个10Hz点；.2明显小于制动峰，同时容许拖曳/量化波动。选最长区间，时长相同选最早，不按速度漂移择优 |
| core漂移 | raw speed端点|Δv|≤.20×core时长+.05m/s | 加速度包络积分加.05端点误差预算；不要求Δv>0，不用恢复比例。额外+.05需P1测量证据确认，证据不足不能冻结 |
| 全间隔漂移 | 报告完整gap的raw Δv、积分正/负剂量；不要求完整gap近零 | 过渡仍可有合理负a，不能只展示core掩盖正恢复 |
| 持续正恢复排除 | 完整gap内a>.20的连续支持≥.30s即FAIL；gap正剂量∫max(a,0)dt>.10m/s即FAIL；a>.40任一点即FAIL | 防止切碎恢复规避持续门槛；.10是半秒×.20的最大允许小波动剂量；.40为near-zero带的两倍。它们是严格构念预算，尚需测量分辨率确认 |
| 低速 | 全窗真实速度<1m/s持续≥.5s为LOW_SPEED_ENDSTOP；速度floor实际触发或出现反向为失效 | 避免用停车平台充当coast。建议P1初速≥5m/s是前瞻适用域提案，不能依据成功个体筛选 |
| 窗口边缘 | 制动或core支持被分析域/数据边界截断不得PASS | 不把未知尾部当完成；本域在7.9s窗内留充足尾部 |

核心内满足漂移不能抵消gap正恢复排除；一个正峰即使净速度仍下降也可能FAIL。实际LQR正命令与轨迹正a均需公开；reference非正却出现持续轨迹正a仍不合格，不以“controller compensation”为豁免。

## 确定性判别顺序与敏感性

先检输入/时间/低速→固定域内找连续a≤−.6支持→按时长/峰/剂量过滤→恰好段数→双段间隔→最长near-zero core→raw漂移→完整gap正恢复排除。短小不合格负波纹仍保留描述；不能合并两个不合格段救成一脚。不沿用旧second_peak_ratio：每脚绝对峰、时长、冲量分别防止第二脚消失。

P1前必须加纯fixture：真coast、轻拖曳、旧+1.4恢复、浅波纹、连续单刹、双峰但无near-zero core、低速、缺帧、时间epoch平移、.1s网格半步边界、±1微秒时间量化、噪声预算±.01m/s。对raw与median3、edge_order=1/2做**固定诊断**，不选最有利方法。若峰差>.2m/s²或任一持续时间变化>.2s，或正恢复排除结论反转，先标MEASUREMENT_UNSTABLE并停止冻结；这些差异预算对应2个采样间隔和near-zero带尺度，不能从结果反调。

本轮测试仅针对解析运动学守恒和非法输入，**尚未实现或验证本表测量classifier**。实现、measurement error实证、阈值Owner审查、版本/代码hash绑定均为P1前置准备。若误差已大到吞没.2近零带，应判当前测量不足，而非扩大近零带使其通过。
