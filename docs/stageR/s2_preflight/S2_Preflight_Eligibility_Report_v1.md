## 科学独立单位

**INDEPENDENCE_UNIT = SESSION。** 同一采集前缀下的不同日志后缀是时间区段。全部组内数据库 `log.timestamp`、`vehicle_name`、`date` 一致，且 208 个会话存在多个分段。因此按不同日志计数会重复计算同一次采集。

车辆 ID 可得，独立驾驶员 ID 不可得；车辆不被冒称为驾驶员。不同会话的路线可能重叠，没有已闭合的跨会话路线依赖证据，因此 SESSION 是当前支持的分组粒度，不是跨会话绝对独立的证明。若需要更高层分组，容量只会进一步下降。没有为了凑数改回 LOG。

## 资格字段的可验证性与限制

执行初始速度 <3.61 的准确排除数、官方路由不足数及其他未绑定资格失败数均为 **null / UNKNOWN**，不是 0。所有候选具有来源指纹，但完整角色来源证明仍未闭合。

分片记录原始标签 token 的速度、时间、scene、任务标签、原始 roadblock 字段与原生时间行支持。它们明确标为 **tag anchor metadata**：

- `NuPlanScenario` 的第一帧来自配置后的场景提取。默认 mapping 中许多类型有 −3 秒 offset，故标签 token 速度可能不是运行起点速度。
- `scene.roadblock_ids` 不是官方 `_route_roadblock_ids`（由原生 expert trajectory 与地图生成）的等价证据。
- 从标签起点每两行取样的 81 个原生时刻只记录 schema 支持，不证明正式配置的 80-state / 79-transition 提取完整性；没有插值或外推。
- rolling reference 继续要求冻结 `_tsb_required_distance(current_speed, absolute_episode_time, arm, params)` 与原生拓扑；当前未证明所有未来 rolling horizons 的支持，不引入新距离/加速度/曲率阈值。
- 完整 replay、正式场景解析、全状态 reset 仍需要执行配置绑定。UNKNOWN 一律不能进入候选合格集，但不记作已观测科学失败。

3.61 m/s 的 inclusive 名义筛选、三项 scope 标签和闭环 LOW_SPEED_ENDSTOP 的 SCIENTIFIC_FAILURE 定义保持冻结。没有使用任何未来机制、安全、F_match 或低速处置结果进行选择。
