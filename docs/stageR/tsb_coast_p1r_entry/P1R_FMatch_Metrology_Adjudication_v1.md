## 实际速度链与精度

真实model的rear-axle速度状态 → `DynamicCarState.speed`（速度向量幅值）→ `realized_current_ego_row` 的Python float → JSON十进制无损往返 → numpy float64。初始日志速度来自已有EgoState，不是新传感器仿真读数。模型后续不添加随机速度测量噪声；被动writer不量化到0.01、不注入噪声，也不使用规划参考替代实现状态。个别元数据摘要会舍入到6位，但**正式raw current-ego writer没有这种舍入**。

只读检查最终已完成B1的40条raw trace、3200个速度值：哈希全部与历史来源索引一致；3200值均可JSON往返精确恢复，也均不位于0.01m/s网格上。这里不重新计算B1 F、机制或资格结论，不据此选择Coast候选。

B1历史采样间隔为99385～100629微秒，说明日志时刻并非精确0.1秒。它们按原合同仍然有效，不能以本轮新精确时钟规则重判旧B1。新候选的实际时间点也已独立核查；没有把历史速度精度当作新时钟通过证据。

## 四项合同完全不变

| 描述符 | 原定义 | caliper |
|---|---|---:|
| mean_speed | 80帧raw speed均值 | .10m/s |
| end_minus_start_speed | raw末−首 | .15m/s |
| path_length | realized rear-axle XY逐段欧氏距离之和 | .80m |
| mean_abs_accel | `mean(abs(np.gradient(raw_speed, physical_time, edge_order=2)))` | .02m/s² |

先整数时间戳减去首时刻再转秒；每个描述符六位舍入，pair delta六位舍入，比较≤caliper+1e−12。没有改为median3、model state acceleration或后向差分。raw gradient度量离散速度序列的变化总强度，可能对高频变化敏感；它不是轮端加速度真值或完整行为语义。保持它作为既有四维匹配摘要，不把四项通过解释为时序结构全部相同。

## 数值预算及界限

对规范80帧/.1秒定义实际构造numpy gradient线性算子，最大行L1范数40s⁻¹。以历史观察到的最大速度尺度，采用保守工程算术预算 `εv=64×float64_eps×max(1,max|v|)=2.046416049e−13m/s`。利用绝对值均值的Lipschitz性，两臂差值预算 `2×40×εv + 1e−6 = 1.000016371e−6m/s²`，远小于.02。这里1e−6覆盖双臂F舍入以及delta再舍入的总量级（保守并入数值预算）。

这是**模型状态提取/既定离散算子/舍入的工程数值预算**，不是经验证的全仿真动力学误差、传感器误差、连续物理导数误差或输入不确定性总上界。JSON本身在已查值上的往返误差为0。完整runner控制敏感性与可重复性尚未运行，不能从隔离模型重复一致推出。接近caliper边界的病例仍按冻结比较规则原样判定，不另给epsilon放宽.02。

## 单臂误差与配对误差

旧固定period4±.01诊断引起单臂F偏移.075～.0825m/s²，恒速null为.10；原反例完全保留。新解析诊断交叉比较固定4×4扰动相位，不选择最优组合；这16种相位的pair绝对差变化最大.0125m/s²。这个较小值只是特定输入下的部分抵消，**不证明任意双臂误差会抵消**。

对任意扰动，配对差不确定性受两臂各自误差之和约束。若真的有各臂±.01未知独立误差，则不能以部分抵消保证.02可判定；应重新阻断并要求测量证据。当前没有这种生产误差证据，所以也不能反过来将该人为包络强制解释为平台误差。

## 精确前瞻修约D2

批准范围仅为：保留压力反例及诊断；正式模型内F仍按原四项、raw梯度、六位舍入、原caliper和有效时间戳判断；**不再将未经证实的±.01压力包络当作生产误差gate**。任何新的实际噪声/量化/不重复证据必须报告并停止，不能事后转算法、扩容caliper或挑seed。

D2未批准，当前程序的科学授权仍关闭；D2批准也不能解决已发现的真实时钟冲突或自动授权首对执行。
