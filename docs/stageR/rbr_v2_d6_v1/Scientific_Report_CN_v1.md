## 4. H30与RBR数值审查：一个重要的新解释

冻结模型、Canonical83、Waymo normalizer、H30全部30列、MMD²/RBF均未修改。`U_SOURCE_COMPLETE_INDEPENDENCE_NOT_ESTABLISHED`保留，未重新认证U来源。未以检测率选数值规则，也未重算任何旧D报警。

官方加速度滤波τ=.2s，dt=.1s，β=2/3。由源码独立推导标量闭式：

`v_n=vx_0+dt·β(1−β^n)/(1−β)·a_0 + dt·Σ_{j=0}^{n−1}(1−β^(n−j))u_j`。

这只计算标量有限和，用来核对已有速度；没有EgoState、位置积分、runner或车辆propagate调用。8个事前hash选定探针n1–79与真实保存速度最大误差约7.11e−15m/s。state0记录的是速度范数，官方模型随后按纵向vx并令vy=0；初次oracle错误地用范数外推，已纠正为保存的vx，原失败日志保留，不更改车辆或历史轨迹。

60条Baseline中，第5秒bin的SD=1.82096365e−10，按初始a0滤波尾巴预测1.82096247e−10，残差SD≈1.18e−15；第6秒bin的SD=3.15785916e−12，预测3.15782751e−12，残差≈1.14e−15。**极小方差主要是真实、确定性滤波对a0的微弱依赖，不是应当全部清除的浮点垃圾。** D4/D5结果不改；D6补充了其物理来源。

在这种Baseline极窄分布上，Treatment约−0.00357m/s²的bin6变化对应非常大的标准化距离，RBF双精度下溢为0主要反映该距离，不能仅为消除0而加floor。任意提高floor可能削弱强H，缺少科学依据。可避免的问题包括绝对1e−12尺度开关的单位依赖（D5已量化）和不稳定3fit；真实大距离与数值错误必须区分。

独立误差界：median3对速度ℓ∞误差是1-Lipschitz；edge_order2差分最大绝对系数和为4/dt，故`||δa||∞≤4 ε_v/dt`，另计浮点舍入。16个固定探针均满足该界；1 ULP扰动产生bin6差异最多约1.42e−15，而预声明±1e−6m/s压力测试产生约2.10e−7。**后一扰动不是实际传感器误差认证**。位置、heading、jerk、ACF等30列的完整物理误差预算仍缺失，不能凭它定floor。

RBR外部3fit的来源稳定性也不足：60个Baseline各列SD/fit scale最大值约5.14；预声明LOO分别可达360.09、29.28、7.86。每种结果都保留，未选任何替代拟合。这不等于encoder塌缩，也不说明固定任意kernel的数学size必然无效。

**认证结论**：标量滤波及选定算子的计算一致性PASS；新q下完整H30/RBR预处理的物理稳健性与跨来源认证BLOCKED。原计算是确定的，但本轮不能交付可信的新单一尺度管线；不指定新floor、不激活D5的max(SD,u_j)。

## 7. 最终科学决策

任务总体、独立来源、测量误差和null必须一致，这个研究问题明确且仍有方法学价值；但目前实现的是标准化采样/原MMD的候选设计、执行前拒绝逻辑和诊断证据，**不是已验证的新条件检验方法**。分层采样＋已有MMD本身不自动构成博士创新。

即使RBR与H30同样敏感，受控基准、可靠性失败分析、可复现的测量/推断界仍可有价值；但未知行为发现、RBR增量、真实道路监控以及独立新方法有效性均未成立。当前双制动应定位为正控制基准，不能单独承担这些主张。

**本轮一次性No-Go：不进入新D采集、Primary或V/C，不继续240源计划。** 保存Level 1基准和统计问题发现；若未来Owner愿意改变资源或来源框，须先独立批准能覆盖缺失任务单元的来源及真实测量证据，不能由本任务自动启动D7或改q救容量。本轮完成后停止。
